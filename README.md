# etf-insight-platform

## Overview
#This project borns with the objective to become an ETF/PAC portfolio, which is able to automatically retrieve, ingest and analyze the information/metadata about ETFs prices,transactions and perform the analysis of the PAC performance. 

## Target user
The target of the platform are the users that already have or are being creating a PAC and they want to analyze the performance and the details behind the shifts of the ETFs contained into. 

## Why it worths it
The main focus of the platform is on the analytics of the ETFs information retrieved and ingested by several sources: 
- The automatic collection of the metadata
- The modeling of portfolios and transactions
- The cleanup of the data and the storage of them
- The computations of key metrics
- Analysis and study of the performance
- Generation of reports and reply to questions by AI layer

## Phases
- Phase 0-1: Ingestion + portfolios + basic metrics
- Phase 2: AI reporting ( monthly explainations, events)
- Phase 3: RAG about ETF docs + Q&A
- Phase 4: evolved architecture + SaaS (eventually)
