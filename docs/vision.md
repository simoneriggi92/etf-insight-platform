## Problem
I have an ETF/PAC, but I don't have a clear vision about performances, risk, allocations, and no one is able to explain me why the things happen and how to smartly improve my handling. 

For instance, I decided to add every month a such amount of money, but I don't know:

- whenever and If I'll need to increase it due the inflaction;
- How are performing ETFs;
- What's the price, TER;
- Which are the risks in the current period;

## Solution
Create platform data which:
- Ingests ETF data (prices, metadata),
- Models portfolios and transactions,
- Calculates key metrics,
- Uses AI to generate reports and answer questions.

## Phases
- Phase 0-1: ingestion + portfolios + basic metrics.
- Phase 2: AI reporting (monthly digest, events).
- Phase 3: RAG about ETF docs + Q&A.
- Phase 4: evolved architecture + SaaS eventually
